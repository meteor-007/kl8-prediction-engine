# 金胆池消融实验与优化整改报告

- 日期: 2026-11-10
- 对象: 快乐8 预测系统 4 码金胆池（超级金胆）
- 方法: 严格 Walk-Forward 因果回测（回测第 T 期只用 1..T-1 期历史）
- 数据: `kl8_history.txt`（截至第 2026299 期，共 2120 期）
- 脚本: `scripts/ablation_gold.py`、`scripts/analyze_ablation.py`、`scripts/analyze_cross_window.py`
- 原始数据: `output/reports/金胆池消融实验_20261110*.json`

---

## 一、结论摘要

1. **4 码金胆池命中率低，第一层原因是数学基线，不是 bug。** 快乐8 每期 80 选 20，任意 4 码的期望命中数恒为 4 × 20/80 = **1.0 码/期**（单码命中率 25%），标准差约 **0.849**。在 60 期窗口里，均值 0.75 与 1.0 的差异远不足以证明模型失效；同期随机基线的均值只有 0.833，本身就说明这个窗口对任何 4 码选择都不友好。

2. **第二层原因是一个真实的结构缺陷：融合权重的尺度问题。** 生产代码 `final_scores = 0.55 × DL概率 + 0.45 × 图谱分数` 中，DL 是 sigmoid 概率（约 0.25 量级），图谱分数是 min-max 到 [0,1] 的分数（方差大得多）。实际效果是：金胆池与 Dirichlet/共现做 Top4 平均重合 **2.62/2.70 码**，与 Transformer 只重合 **0.67/4 码**——"55% DL 权重"名不副实，金胆几乎由慢变的谱分量决定。

3. **第三层原因是金胆池粘滞。** 60 期里只出现过 34 个不同号码（共 80 个）；号码 73 曾连续 **20 期**留在金胆池；相邻两期平均 Jaccard 相似度 0.492；金胆命中数的 lag-1 自相关 +0.201，**有效独立样本约 40 期而不是 60 期**。一个几乎不换号的池子，长期表现会被少数几个号码的冷热周期锁死。

4. **排序质量没有正向信号。** 对 80 码整体排序计算 AUC（随机=0.5）：三个 60 期窗口里，fused 分别为 0.482、0.495、0.487，DL 为 0.480、0.492、0.494，共现谱为 0.481、0.496、0.494。所有分量都在 0.5 附近或略低，没有任何得分源显示出稳定可用的预测试信号。DL 训练 BCE 0.551，而常数 0.25 预测的 BCE 为 0.562，只好了 0.011 nats（且是训练集）。

5. **Borda 秩融合是证据支持的整改，但它是"修结构"，不是"造优势"。** 对 DL / Dirichlet / 共现谱 / 动量四分量做等权秩融合后：
   - 三个 60 期窗口金胆均值：**1.217 / 1.217 / 1.183**；同期生产融合为 0.750 / 1.083 / 0.933；同期随机基线为 0.833 / 1.117 / 1.100。
   - 合并 180 期：Borda **1.206** vs 生产融合 0.922（配对差 +0.283，p=0.0040）；Borda vs 随机 1.017（差 +0.189，p=0.0579）。
   - 全排序切换到 Borda 后，主选/Top20/30码大底在两个验证窗口均未变差（多数小幅改善，未达显著）。
   - **但对随机基线仍未达到显著优势**，且四个分量的 AUC 仍≈0.49。因此不能宣称"提高了预测准确率"。

6. **最终判断：** 当前系统在公平开奖上不具备可证明的预测优势。Borda 整改修复了"谱分量尺度绑架 + 金胆粘滞"的结构问题，使金胆池回到与随机基线相当或略好的水平；接下来的正确目标不是继续调命中率，而是用 500+ 期与 AUC 主指标做长期监控，确认是否存在任何微弱信号。

## 二、实验设计

### 2.1 选择器（17 个，同一期共享同一套因果得分）

| 类别 | 选择器 | 说明 |
| :--- | :--- | :--- |
| 生产基线 | `fused_top4` | 0.55×DL + 0.45×谱分数，取 Top4 |
| 单分量 | `dl_top4` / `dirichlet_top4` / `cooc_top4` / `momentum_top4` / `spectral_top4` | 各分量单独 Top4 |
| 秩融合 | `borda4_top4` / `borda3_top4` / `borda_dl_spectral_top4` | 四分量 / 三分量 / DL+谱 的 Borda 秩融合 |
| 频率基线 | `hot50_top4` / `cold50_top4` | 近 50 期最热 / 最冷 4 码 |
| 重号规则 | `norepeat_fused_top4` / `repeatonly_fused_top4` | 排除上期号码 / 只从上期号码中选 |
| 形态约束 | `zone1_fused_top4` / `zone2_fused_top4` / `balanced_fused_top4` | 每 20 号分区最多 1 个 / 最多 2 个 / 奇偶 2:2 |
| 对照 | `random_top4` | 每期固定种子随机 4 码 |

### 2.2 统计口径

- 每期训练一次 Transformer（epochs=25, seq_len=10），从同一组得分派生全部选择器，保证配对可比。
- 主要指标：4 码命中数均值、Lift、P(≥2 码)、排序 AUC。
- 配对检验：同一期上比较两个选择器的命中差，消除期际难度波动。
- 多重比较：17 个选择器，Bonferroni 阈值 0.05/17 ≈ 0.0029。
- 三个互不重叠的 60 期窗口（2026120–2026179、2026180–2026239、2026240–2026299），合并 180 期。

### 2.3 理论基线

- E[命中] = 1.0 码/期；SD = √(4×0.25×0.75×76/79) ≈ 0.849。
- P(≥2 码) = 0.259；P(≥1 码) = 0.6917；P(中 4 码) = 0.306%。
- 要检测 10% 的真实优势（1.0→1.1），约需 500+ 期；几十期回测不足以区分"无技能"与"微弱优势"。

## 四、为什么命中率低：三层解释

### 4.1 统计层：4 码池的方差极大

4 码命中数的标准差是 0.849，约等于均值本身；60 期的均值标准误约 0.11（考虑粘滞后约 0.13）。0.75 与 1.0 的差距约 1.9–2.5σ，在同时观察 17 个选择器、多个窗口时完全不构成"模型失效"的证据。文献中的功效分析表明，检测 20% 的真实优势约需 142 期，检测 10% 约需 566 期；几十期回测的结论只能是"观察"。

### 4.2 结构层：名义权重与真实影响力不符

`sigmoid` 概率集中在 0.25 附近，方差很小；`_normalise` 后的谱分数铺满 [0,1]，方差大。直接加权和让谱分量主导 Top4。这与 `docs/8.md` 中"Borda 百分位秩归一化"的设计描述不一致，属于实现与设计脱节。Borda 秩融合把每个分量先转成 1..80 的名次，从根本上消除了量纲问题。

### 4.3 行为层：金胆池在追"历史热号/重号"

金胆池与近 50 期最热 4 码平均重合 2.02/4，与"只从上期开奖号码中选"的规则平均重合 1.93/4。也就是说，金胆在系统性地追热号和重号。行为经济学文献（gambler's fallacy / hot hand）表明这是人类选号的常见偏差；在公平开奖下，它不改变期望，只会增加方差和解释错觉。本次窗口里冷号基线（cold50 1.167）反而略高于热号（hot50 0.917），也印证了"追热"在本窗口没有回报——但这同样可能只是窗口噪声。

**对本次整改的直接启示：**
- 对最终融合分数做 Platt/isotonic/温度缩放不会改变 Top4（严格单调变换），不能提高命中率；校准只适合做概率解释/资金分配。

## 六、已实施的整改

### 6.1 生产融合改为 Borda 秩融合（默认）

- `kl8_engine/models/ensemble.py`
  - 新增 `rank_percentile_scores()`：把任意分量转成 1..80 的百分位秩。
  - 新增 `borda_fusion_scores()`：对 DL / Dirichlet / 共现谱 / 动量四分量等权秩融合。

- 报告头部显示当前融合方式；`PipelineResult.fusion_mode` 可审计。

## 七、局限与后续建议

1. **样本量不足**：3 × 60 期只能给出方向性证据；Borda vs 随机的 p=0.058 仍未显著。下一步应在 500+ 期上复跑，并用 block bootstrap（块长 2–5）处理金胆粘滞导致的自相关。
2. **AUC 仍是 0.49**：如果 500 期后所有分量的 AUC 置信区间仍包含 0.5，应接受"公平开奖不可预测"，把系统定位为数据分析/娱乐工具，而不是提高命中率的模型。
3. **低容量排序模型**：在确认 AUC>0.5 之前，不建议加更复杂的 Transformer。若要试，优先 LightGBM LambdaRank / pairwise logistic / BPR，用现有四个分量 + 遗漏/分区特征，内层验证早停。
4. **不要以命中率为调参目标**：公平彩票上这是拟合噪声。后续优化应预注册 1–2 个假设，报告 AUC、hit@k、Lift 与 bootstrap CI，并做多重比较校正。
5. **今日已发布推荐不重算**：第 2026300 期报告是在整改前生成的（weighted 融合），推荐日志已记录首份推荐；为保持审计完整性，不事后覆盖。Borda 从下一次日常运行（第 2026301 期）开始生效。
